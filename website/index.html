Axle CLI v1.3.0

A Modular Platform for Python Microtools

Run ANY Python tool by name or number — flags pass straight through. Interactive arrow-key menu, per-tool usage examples, and intelligent auto-discovery. No contract required.

Get Started View on GitHub
$ pip install git+https://github.com/skpaul82/axle-cli.git

Why Choose Axle?

🖱️

Interactive Menu

Run axle with no arguments to get a scrollable arrow-key tool picker. Navigate, select, type your args — done.

⚡

Direct Execution

axle tool_name --flags or axle 4 --flags — run any tool by name or number. Flags pass straight through. No axle run needed.

📌

Per-Tool Examples

Type axle tool_name with no args to see that tool's own usage examples — automatically extracted and shown with axle prefix.

⚙️

Modular Platform

Drop any Python script into your tools directory and run it instantly. Argparse tools, prompt tools, and multi-function scripts all work. No contract required.

🔒

Optional Security

Pre-execution validation scans tools for security issues. Disabled by default for speed — enable per-run with --security or globally with axle security --enable.

🔍

Optional Code Review

Automatic code quality checks and auto-fixing. Enable per-run with --code-review or globally with axle review --enable.

📦

SEO & Content Tools

Keyword checker, meta tag auditor, competitor analysis, content optimizer, and content brief generator — all built in.

Quick Start

1

Install Axle

pip install git+https://github.com/skpaul82/axle-cli.git
2

Launch Interactive Mode

axle

Arrow-key menu — pick a tool, type your args, run it.

3

Or Run Directly by Name or Number

axle competitor_analysis --urls https://rival.com --target-keyword "web developer" axle 4 --urls https://rival.com --target-keyword "web developer"
4

See Tool Examples

axle content_optimizer

Shows that tool's own usage examples — converted to axle syntax automatically.

5

Add Your Own Tools

Drop any Python script in your tools directory. Works with argparse tools, prompt tools, and multi-function scripts — no contract needed.
